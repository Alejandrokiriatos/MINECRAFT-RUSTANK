# Decisiones técnicas

- El producto final es un **servidor dedicado público**, no un modpack para un mundo individual.
- La lógica de juego se implementará en un mod Forge que se ejecuta en el servidor.
- Los jugadores deberán instalar cliente compatible con Minecraft 26.1.2, Forge 64.1.5 y el mod Rustank.
- Versión Forge fijada inicialmente en 64.1.5 (build recomendado en la página oficial consultada el 11-11-2026).
- Java objetivo: 25.
- La whitelist permanecerá activada durante desarrollo y pruebas; se desactivará únicamente cuando el servidor esté preparado para abrirse.
- No se combinará Forge con Paper/Spigot: son plataformas diferentes y no se deben mezclar arbitrariamente.
