# Despliegue público — pendiente

El servidor no debe anunciarse como público hasta superar pruebas de arranque, compatibilidad cliente/servidor y carga.

Requisitos mínimos previstos:
- Host Linux o Windows con JDK 25.
- Forge dedicado 26.1.2-64.1.5.
- RAM y CPU dimensionadas mediante pruebas reales.
- Dirección pública estable y firewall configurado.
- TCP 25565 permitido solo cuando el servidor esté listo.
- `online-mode=true`, whitelist durante pruebas y cuentas administrativas protegidas.
- Backups automáticos fuera del directorio del mundo.
- Plan de restauración y moderación.

Los jugadores necesitarán instalar Minecraft 26.1.2, Forge 64.1.5 y el mismo conjunto de mods del servidor.
